## Primary gameplay promise and acquisition

The existing mod changes **Create powered train fuel consumption according to speed**: `TrainMixin` replaces `Train.burnFuel()` when the common config is enabled. `TrainFuelCostCalculator` converts absolute blocks/tick to blocks/second, computes `baseCost * exp(k * (speed/normalMax - 1))` bounded by configured minimum/maximum, and accumulates fractional per-train fuel debt. By default normal maximum speed costs one fuel tick per call, faster motion costs more, stopped motion does not drain, and reverse motion uses the same magnitude as forward. The normal maximum comes from Create's `poweredTrainTopSpeed` (fallback 40 bps). When fuel runs out, the mixin scans carriage fuel item handlers in direction-of-travel order, extracts a burnable item using Forge burn time, and attempts to return any crafting remainder. It writes the debt to `CreateTrainFuelScalingFuelDebt` in train NBT and restores finite nonnegative debt on read. Config defaults/ranges are in `TrainFuelScalingConfig`; the permission-2 `/better_create_train_fuel formula <speedBps>` command reports a calculated cost. `TrainFuelConsumedEvent` is emitted only for qualifying excess consumption with a server and train owner; it is not a guarantee of client UI feedback.

This repository registers **no new item, block, recipe, loot, or acquisition chain**. Obtain/Create trains and their carriage fuel inventory through Create's existing mechanics; coal (`Items.COAL`) and lava buckets (`Items.LAVA_BUCKET`) are vanilla acquisition references used in `TrainFuelScalingGameTests`, not mod-added rewards. Coal's Forge burn time and lava bucket's bucket remainder are tested as API availability, not proof of a populated, movable, refueling train. See `src/main/java/.../mixin/TrainMixin.java`, `config/TrainFuelScalingConfig.java`, `command/TrainFuelScalingCommands.java`, and `src/main/resources/META-INF/mods.toml`. No GUI or recipe root is contributed here; full-pack recipe/GUI qualification must still verify the actual Create fuel supply and any pack-specific recipe/access changes.
